# 🧰 技術スタック

- 🌐 **HTML/CSS/JavaScript**（フロントエンドページ、カードおよび操作アニメーション、学習行動に関連する処理ロジック）
- 📱 **Apicloud**（Android アプリへのパッケージング）
- 🧭 **PHP**（バックエンド API、フロントエンドへのデータ提供。新しいデータの取得や同期操作が不要な場合、オフラインで使用可能）
- 🗄️ **MySQL**（日本語資料、知識ポイントの習熟度、学習時間などの保存）
- 🐍 **Python**（データベースへのデータ一括追加：単語、文法、リスニング、JLPT 過去問など... 資料は豊富にあります）
- 🌿 **Git**（バージョン管理。個人プロジェクトであっても、バージョン管理は必須です）
- 🤖 **ChatGPT**（万能プログラミングアシスタント。GPT がなければ、このプロジェクトは完成しなかったでしょう。あるいは、完成までにさらに多くの時間を要したはずです）

# 📖 画面紹介

  - **APICloud フレームワーク初期化** - モバイルハイブリッド開発フレームワークに基づいています

  - **学習同期情報の表示** - 学習データ同期プロセスのログ情報を表示
  - **プログレスバーコンポーネント** - 同期の進捗状況とステータステキストをリアルタイムで表示
  - **ウィンドウライフサイクル管理** - アプリのフォアグラウンド/バックグラウンド切り替えイベントの監視
  - **ページルーティング制御** - 関連ウィンドウを自動的に閉じ、カテゴリページへ遷移
  - ...

- category.html

  - **カテゴリ表示画面** - 復習待ちノートのカテゴリリストと数量統計を表示
  - **スマートカテゴリ推奨** - ノートのレベルと数量に基づいて、重点的に復習すべきカテゴリを推奨
  - **インタラクティブなカテゴリ選択** - カテゴリの単一選択と複数選択をサポートし、振動と効果音によるフィードバックあり
  - **カテゴリ管理機能** - カテゴリをダブルクリックすることで、名前の変更、削除、昇格、降格の操作が可能
  - **データ同期の整合** - ページ初期化時にノートデータを自動的に整合
  - ...

- category-search.html

  - **カテゴリ検索画面** - カテゴリ名のあいまい検索と複数キーワードの AND 検索を提供
  - **検索履歴管理** - 検索履歴を記録・表示し、クリックで素早く検索可能
  - **ワイルドカード対応** - "\*" ワイルドカードによる全カテゴリ表示に対応
  - **インタラクティブな履歴記録** - 履歴をクリックして素早く入力、長押しで削除可能
  - **削除の復元機能** - 誤って削除した検索履歴をメッセージプロンプトから復元可能
  - **グラデーション背景デザイン** - 検索回数に応じて異なる色のグラデーション背景を表示
  - ...

- list.html

  - **ノート一覧表示** - 復習待ちノートをページ分割で表示し、クリック選択とステータス切り替えをサポート
  - **ジェスチャー操作** - シェイクしてオーディオリストを再生、左右スワイプでカードページへ遷移
  - **複数選択一括操作** - ノートを複数選択して一括で昇格/降格処理が可能
  - **オーディオリストプレーヤー** - 横画面全画面プレーヤー、プログレスバーとスキップ機能をサポート
  - **リアルタイム翻訳表示** - ノートをクリックして日中対訳翻訳を表示
  - **グループ再生モード** - 日本語 3 回 + 中国語 1 回のグループループ再生をサポート
  - ...

- card.html
  - **シングルカード学習モード** - 単一のノートカードを全画面表示し、裏返して答えを確認可能
  - **スマート復習アルゴリズム** - エビングハウスの忘却曲線に基づいた間隔反復復習システム
  - **ジェスチャー操作制御** - 左右スワイプでカード切り替え、上下スワイプで記憶レベル調整
  - **記憶レベル評価** - 6 段階の記憶レベルシステムにより、復習間隔を動的に調整
  - **進捗追跡表示** - 学習進捗と残りのカード枚数をリアルタイム表示
  - **自動保存メカニズム** - 学習記録をローカルデータベースに自動保存
  - **Markdown レンダリング** - Markdown 形式のノート内容の編集と表示をサポート
  - **音声コメント機能** - 学習資料にテキストまたは音声のメモを追加可能
  - ...

# ノートの優先順位付け（復習推奨）

- 記憶効率を向上させるには、適切なタイミングで適切な回数を繰り返す必要があります
- 学習タスクが膨大でカテゴリが多い場合（単語資料、文法資料、リスニング資料、読解資料など...）
- このような状況では、現在の時間においてどの内容を優先的に復習すべきか、記憶効率を最大化するために人為的に判断することは困難です
- そこで、プログラムが自動的に選択を行い、復習資料の優先順位付けを行い、その順序に従って復習を行う必要があります
- カテゴリ画面にはデフォルトで、現在優先的に復習すべきノートカテゴリが表示されるため、少なく見えることがありますが、これが全てのノートではありません

> ⬇️ 優先順位付けの例

![](./assets/20251021212628609.png)

- 現在、別のカテゴリを復習したい場合や、カテゴリ内の全てのノートを確認したい場合はどうすればよいでしょうか？
- その場合は、カテゴリ検索画面を使用する必要があります

# ノートの一括操作

- ノートの複数選択、一括昇格/降格に対応
- ハイライトされたノート（習得済みとしてマークされたノート）は、一律レベル+1
- 取り消し線のあるノート（未習得としてマークされたノート）は、一律レベル-1
- ノートを素早く処理し、学習効率を向上させることができます
- 既に大部分の内容を習得しており、少量の内容のみ復習が必要な場合に適しています

> ⬇️ ノートがマークされている状態で、長押しまたはシェイクすると、ノートを一括処理できます

# カード操作

- カードは上下左右のスワイプに対応しています

> ⬇️ ノートを上スワイプ：正解（記憶済み）、レベル+1（次回の復習時間をポップアップ表示）

<img src="./assets/20251024162741210.gif" width="40%" alt="カード上スワイプ概略図"/>

> ⬇️ ノートを下スワイプ：不正解（未記憶）、レベル-1（次回の復習時間をポップアップ表示）

# リスニングモードと通常モードの違い

- リスニングモード：耳だけで学習する場合に適しており、操作が簡単で誤操作を防ぎます。ランニングや通勤など、画面を見ることが難しいシーン向けです。
- 通常モード：目と耳を使って学習する場合に適しており、操作が豊富で内容のスクロール表示に対応しています。自宅や自習室など、画面に集中できるシーン向けです。

# 🗺️ 今後の計画

- Kotlin を使用してアプリを書き直し、パフォーマンスとユーザー体験を向上させる
  - パフォーマンスをさらに向上させ、操作をよりスムーズにし、ゲームのような滑らかな連続操作感を実現
  - より多くのインタラクティブアニメーションを追加し、アプリの使用感を高め、学習をゲームのように楽しませる
- スマートウォッチとの連携を追加し、混雑した場所でも時計を通じて学習プロセスを完了できるようにする
- ジェスチャー操作、音声コントロール、アイトラッキングなど、より実用的な機能を追加
  - ジェスチャー操作：ジムでのランニング中などに、手振りでアプリの操作（カード切り替え、音声再生など）を制御

  - PC 版ウェブページを通じて、みんなの学習進捗やステータスを確認でき、ランキングを通じて互いに監督し励まし合うことができる
  - 学習資料の追加をより便利にし、ユーザー自身が学習資料を作成・共有できるようにする
  - 将来的に必要であれば、PHP から GoLang などのより高性能なバックエンド技術スタックへの移行を検討
